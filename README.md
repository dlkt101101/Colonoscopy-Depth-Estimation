# Colonoscopy Depth Estimation

This repository is an extension of my coursework project where I fine-tuned a hybrid transformer model DPT-Hybrid for monocular depth estimation on colonoscopy footage.

The extension of this project is to apply MLOps practices by:
	1. Cleaning up and restructuring the codebase
	2. Experiment tracking with MLflow 
  3. Model serving with FastAPI
	4. Containerize with Docker
	5. Cloud Deployment usign Azure
	6. Basic Model Monitoring by feeding model out of sample images.
